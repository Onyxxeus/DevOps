Linux commando's

De belangrijkste commando's voor de terminal, op een rij.

Nano

nano = opent een bestand in een teksteditor

Echo

echo = print een tekst in een terminal

Cd

cd = verandert je directory waar je in zit

Pwd

pwd = print de directory waar je in zit

Ls

ls = print een lijst van files of informatie over de directory waar je in zit

Mkdir

mkdir = maakt een nieuwe directory aan

Rmdir

rmdir = verwijdert een directory

Touch

touch = maakt een leeg tekstbestand aan

Rm

rm = verwijdert een specifiek bestand wat je selecteert

Mv

mv = verplaatst een bestand

Cp

cp = kopieert een bestand

Chmod

chmod = verandert de rechten van de persoon die het commando uitvoert

Cat

cat = print de inhoud van een bestand

Less

less = print de inhoud van een bestand maar in een meer samengevatte manier

Tail

tail = print de laatste regels van een bestand

Head

head = print de eerste regels van een bestand

Tree

tree = print de hele structuur van een directory

Man

man = print de uitleg pagina van een specifiek commando

Ctrl + O (in een file)

Ctrl + O (in een file) = slaat een bestand op

Ctrl + X (in een file)

Ctrl + X (in een file) = sluit een file af

Ip a

ip a = print de ip adres van een computer

Sudo

sudo = voert een commando uit als de gebruiker root is

Ssh

ssh = stelt een verbinding met een server op
